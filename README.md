# Ceylan Academic - Educational Web Platform (React + TypeScript)

[![Live Demo](https://shields.io)](https://a00ae.github.io/Ceylan-Academic/)

A comprehensive, modern educational platform web application. Built with high-performance standards using **React 18, TypeScript, and Vite**, this platform showcases full-scale frontend architecture tailored for educational management, course displays, and seamless student-instructor workflows.

## 🚀 Live Preview
Explore the fully interactive educational live website here: **[Live Demo Link](https://a00ae.github.io/Ceylan-Academic/)**

## 🛠️ Tech Stack
* **Framework:** React 18 (Functional Components, Custom Hooks)
* **Type Safety:** TypeScript (Strictly typed schemas for educational data)
* **Build System:** Vite (Highly optimized bundling and fast HMR)
* **Routing:** React Router DOM (Dynamic nested routes for portal navigation)
* **Styling:** CSS / SCSS (Scalable and modular UI stylesheets)

## ✨ Key Features
* **Modular Dashboard Layouts:** Robust interface architecture catering to educational content organization and navigation.
* **Dynamic Route Protection:** Implements modular rendering paths for students and administrative views.
* **Component Reusability:** Features clean abstractions for repeating UI cards, lists, filtering dropdowns, and form interfaces.
* **Type-Safe Data Flow:** Full TypeScript enforcement across simulated backend payloads, reducing edge-case application breaking.
* **Responsive Fluid Design:** Pixel-perfect rendering across wide workspace screens, laptops, tablets, and smartphones.

## 📂 Architecture and Code Quality
This repository follows corporate-ready development practices:
* Strict ESLint configuration tailored for type-aware lint rules.
* Separation of concerns: presentation components are cleanly decoupled from state configurations.
* Future-proof development optimized for the new **React Compiler** workflow capabilities.

## ⚙️ Local Installation
Run this project in your local development environment:

1. Clone this repository:
   ```bash
   git clone https://github.com](https://github.com/a00ae/Ceylan-Academic.git
   ```
2. Navigate to the project root directory:
   ```bash
   cd Ceylan-Academic
   ```
3. Install the dependencies:
   ```bash
   pnpm install  # or npm install
   ```
4. Run the development server:
   ```bash
   pnpm dev      # or npm run dev
   ```
